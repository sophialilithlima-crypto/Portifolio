# Sophia Lilith — Portfolio

Portfólio pessoal de Sophia Lilith, estudante do ensino médio e desenvolvedora em formação.

O projeto foi inspirado na organização do portfólio de referência fornecido pelo meu pai, com uma estrutura moderna em Astro, React, Tailwind CSS e TypeScript.

## Tecnologias do portfólio

- Astro
- React
- Tailwind CSS
- TypeScript
- GitHub Pages

## Seções

- Apresentação
- Sobre mim
- Tecnologias
- Projetos
- Objetivo
- Idiomas
- Contato
- CV em formato próprio para impressão

## Projetos apresentados

- [Pokédex](https://github.com/sophialilithlima-crypto/Pokedex)
- [Desafio React 3](https://github.com/sophialilithlima-crypto/desafio-react3)

## Rodar localmente

```bash
npm install
npm run dev
```

Depois, acesse o endereço mostrado pelo Astro, normalmente:

```text
http://localhost:4321
```

## Gerar versão de produção

```bash
npm run build
npm run preview
```
